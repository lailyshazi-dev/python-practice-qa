## Что понял

- `pytest.approx(expected)` сравнивает дробные числа приблизительно.
- В `pytest.approx` можно явно указать допустимую погрешность.
- `abs=0.01` означает, что фактический результат может отличаться от ожидаемого максимум на `0.01`.
- Такая проверка полезна, когда результат округляется или вычисляется с небольшой погрешностью.
- Обычный `==` не всегда удобен для проверки float-значений.

## Где это нужно в реальной работе

- UI показывает рейтинг товара как `4.7`, а API возвращает `4.67`.
- Отчет показывает процент `33.33`, а расчет внутри системы дает `33.333333`.
- API возвращает среднее время ответа около `0.25`, но точное значение немного меняется.
- Геосервис возвращает координаты или расстояние с округлением.
- Аналитика и статистика часто работают с дробными значениями, где важна допустимая погрешность.

Важно: для денежных расчетов обычно используют `Decimal`, а не обычный `float`.

## Код дня

```python
def test_average_returns_approx_result_with_tolerance():
    assert average(1, 2) == pytest.approx(1.5, abs=0.01)
```

## Как это читать

- `average(1, 2)` возвращает фактический результат.
- `pytest.approx(1.5, abs=0.01)` задает ожидаемое значение и допустимую погрешность.
- `abs=0.01` разрешает отличие максимум на одну сотую.

## Новые слова

- `tolerance` - допустимая погрешность.
- `absolute tolerance` - абсолютная погрешность.
- `abs` - параметр абсолютной погрешности в `pytest.approx`.
- `rounding` - округление.
- `float comparison` - сравнение дробных чисел.

## Правило дня

Если дробный результат может немного отличаться из-за округления или особенностей вычислений, используй `pytest.approx` с понятной погрешностью.
