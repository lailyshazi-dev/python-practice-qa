## Где это нужно в реальной работе

- Новый QA открывает проект и сразу видит, как запустить тесты.
- Разработчик перед релизом запускает только быстрые API-проверки.
- CI использует команды из README как основу для pipeline.
- Работодатель на GitHub видит, что проект можно реально запустить, а не просто прочитать код.
- Команда не тратит время на вопросы вроде “какой командой запускать API-тесты?”.

## Команды дня

```powershell
python -m pytest
python -m pytest -q
python -m pytest tests/api -q
python -m pytest -m api -q
python -m pytest -m "api and negative" -q
python -m pytest -m "api and not negative" -q
python -m pytest --html=reports/report.html --self-contained-html
```
