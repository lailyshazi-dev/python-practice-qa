# День 39: выборочный запуск тестов в pytest

## Что я сделал

- Создал ветку `docs/add-pytest-targeted-run-lesson`.
- Повторил запуск всех тестов проекта.
- Запустил один конкретный файл с тестами.
- Запустил один конкретный тест по полному имени.
- Запустил тесты по части названия через `-k`.
- Разобрал, почему `-k "update and status"` выбрал 2 теста, а не 1.

## Что понял

- Не всегда нужно запускать весь проект целиком.
- Если работаешь с одним файлом, можно запускать только этот файл.
- Если исправляешь один сценарий, можно запускать только один тест.
- `-k` помогает искать тесты по части имени.
- `-k` смотрит не только на имя теста, но и на связанные ключевые слова: имя файла, класса, маркеры и другие pytest keywords.
- Поэтому команда `pytest -k "update and status"` может выбрать тесты, где слово `update` есть в названии файла, а `status` есть в названии теста.

## Где это нужно в реальной работе

- Ты исправляешь баг в API-методе обновления поста и сначала запускаешь только `tests/api/test_update_post.py`, чтобы быстро проверить нужную область.
- Ты меняешь один конкретный тест `test_update_post_status_code` и запускаешь только его, чтобы не ждать весь набор тестов.
- Перед коммитом ты запускаешь уже все тесты проекта, чтобы убедиться, что изменения ничего не сломали.
- В CI/CD обычно запускается весь набор тестов, а локально разработчик часто запускает только нужный файл или один тест для скорости.
- Когда тестов станет 500 или 2000, выборочный запуск экономит много времени и помогает быстрее находить ошибку.

## Команды дня

Запуск одного файла:

```powershell
.\.venv\Scripts\python.exe -m pytest tests/api/test_update_post.py
```

Запуск одного конкретного теста:

```powershell
.\.venv\Scripts\python.exe -m pytest tests/api/test_update_post.py::test_update_post_status_code
```

Запуск тестов по части названия:

```powershell
.\.venv\Scripts\python.exe -m pytest -k update
```

Запуск тестов по нескольким условиям:

```powershell
.\.venv\Scripts\python.exe -m pytest -k "update and status"
```

Запуск всех тестов:

```powershell
.\.venv\Scripts\python.exe -m pytest
```

## Новые слова

- `nodeid` - полное имя теста в pytest, например `tests/api/test_update_post.py::test_update_post_status_code`.
- `-k` - фильтр pytest для запуска тестов по части названия или ключевым словам.
- `deselected` - тесты, которые pytest нашел, но не запустил из-за фильтра.
- `targeted run` - выборочный запуск тестов.

## Правило дня

Во время разработки запускай маленькую группу тестов для скорости, а перед коммитом запускай весь проект.
